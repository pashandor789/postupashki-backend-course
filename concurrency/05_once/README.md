# Once

Выполнить функцию ровно один раз, сколько бы горутин её ни попросили.
Классический пример — ленивая инициализация: соединение с базой, разбор
конфига, построение таблицы.

Заманчиво написать так:

```go
if !done {
    done = true
    f()
}
```

Это сломано трижды: `done` читают и пишут без синхронизации; двое могут
пройти проверку одновременно; и главное — второй вызов вернётся сразу,
хотя `f` ещё не закончила, и увидит наполовину построенное состояние.

Поэтому состояний три: ещё не начинали, кто-то выполняет, готово.
Победитель гонки выполняет `f`, остальные **ждут**, пока он закончит,
и только потом возвращаются.

Отдельно решите, что делать, если `f` паникует. Стандартная библиотека
считает такой вызов состоявшимся и больше `f` не запускает — иначе следующий
вызывающий получил бы наполовину проинициализированное состояние.

## Что реализовать

`Do(f func())` и `Done() bool`.
