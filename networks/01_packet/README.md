# 01. Разбор заголовков кадра

Программа получает на стандартный ввод шестнадцатеричный дамп одного кадра Ethernet
и печатает на стандартный вывод значения полей заголовков по уровням.

Разбираются: кадр Ethernet II, пакет IPv4, сегмент TCP или дейтаграмма UDP.

## Ввод

Одна или несколько строк с шестнадцатеричными цифрами. Пробелы, переводы строк и
двоеточия игнорируются. Регистр букв любой.

```
001b213c4d5e 0025645d1e22 0800
4500003c1c464000400600000a000002 5db8d822
a86a0050 12345678 00000000 a002faf0 00000000
```

## Вывод

Построчно, `ключ значение`, разделитель — один пробел. Порядок строк произвольный.
Лишние строки игнорируются, поэтому отладочный вывод допустим, если он не начинается
с перечисленных ключей.

### Уровень Ethernet

| ключ | значение |
|---|---|
| `eth.dst` | адрес назначения, шесть октетов через двоеточие в нижнем регистре |
| `eth.src` | адрес источника в том же виде |
| `eth.ethertype` | поле типа: `0x0800`, `0x86dd`, `0x0806` и подобные |

### Уровень IPv4

Выводится, если `eth.ethertype` равно `0x0800`.

| ключ | значение |
|---|---|
| `ip.version` | версия протокола |
| `ip.ihl_bytes` | длина заголовка в байтах |
| `ip.total_length` | значение поля общей длины |
| `ip.id` | идентификатор в виде `0x1c46` |
| `ip.flags` | `DF`, `MF` или `none`; при двух установленных — `DF,MF` |
| `ip.frag_offset` | смещение фрагмента в байтах |
| `ip.ttl` | значение поля времени жизни |
| `ip.protocol` | номер протокола вышестоящего уровня |
| `ip.src`, `ip.dst` | адреса в десятично-точечной записи |
| `ip.checksum_valid` | `true`, если контрольная сумма заголовка сходится, иначе `false` |

### Уровень TCP

Выводится, если `ip.protocol` равно 6.

| ключ | значение |
|---|---|
| `tcp.src_port`, `tcp.dst_port` | номера портов |
| `tcp.seq`, `tcp.ack` | номер последовательности и номер подтверждения |
| `tcp.data_offset_bytes` | длина заголовка в байтах |
| `tcp.flags` | перечисление через запятую без пробелов в порядке `FIN,SYN,RST,PSH,ACK,URG`; при отсутствии установленных — `none` |
| `tcp.window` | размер окна |

### Уровень UDP

Выводится, если `ip.protocol` равно 17.

| ключ | значение |
|---|---|
| `udp.src_port`, `udp.dst_port` | номера портов |
| `udp.length` | значение поля длины |

### Полезная нагрузка

| ключ | значение |
|---|---|
| `payload.length` | число байт данных после заголовка транспортного уровня |

Если `eth.ethertype` не равно `0x0800`, выводятся только поля уровня Ethernet.
Если `ip.protocol` не равно 6 и не равно 17, поля транспортного уровня не выводятся,
а `payload.length` считается от конца заголовка IPv4.

## Что потребуется учесть

1. Длина заголовка IPv4 задаётся полем IHL в 32-разрядных словах и может превышать 20 байт.
2. Поле флагов и смещение фрагмента занимают одно 16-разрядное поле: три бита флагов и
   13 бит смещения; смещение задано в единицах по восемь байт.
3. Контрольная сумма заголовка считается как дополнение до единицы суммы 16-разрядных слов
   заголовка, причём само поле контрольной суммы при подсчёте принимается нулевым.
4. Длина заголовка TCP задаётся полем смещения данных в 32-разрядных словах.
5. Дамп может содержать дополнение кадра до минимальной длины: ориентироваться следует
   на поле общей длины в заголовке IPv4, а не на размер входных данных.

```
make 01
```
