# Домашняя работа: сетевые примитивы

Пять независимых заданий. В каждом требуется реализовать то, что разбиралось на лекции:
разбор заголовков, адресацию, запрос к системе доменных имён, разбор сообщения HTTP
и повторную отправку запроса.

## Язык не имеет значения

Проверяется поведение программы, а не её исходный код. Задания можно выполнять на любом
языке: тесты запускают вашу программу как процесс и общаются с ней через стандартный
ввод-вывод и сетевые сокеты.

Требования к каждому заданию одинаковы:

1. В каталоге задания лежит исполняемый файл `run.sh`, который запускает вашу программу.
2. Если решение требует сборки, рядом лежит `build.sh`; тесты вызывают его один раз перед запуском.
3. Программа не обращается в интернет. Все адреса, к которым нужно обращаться, передаются
   в аргументах командной строки.
4. Программа завершается с кодом 0 при успешной обработке и с ненулевым кодом при ошибке.
5. Вывод программы соответствует формату, описанному в задании, — построчно, `ключ значение`.
   Порядок строк значения не имеет, лишние строки допускаются и игнорируются.

Пример `run.sh` для разных языков:

```sh
#!/bin/sh
exec python3 main.py "$@"
```

```sh
#!/bin/sh
exec ./packet "$@"          # рядом build.sh с вызовом компилятора
```

```sh
#!/bin/sh
exec node main.js "$@"
```

## Задания

| каталог | тема | обязательное |
|---|---|---|
| `01_packet` | разбор заголовков кадра: Ethernet, IPv4, TCP и UDP | да |
| `02_subnet` | адресация и выбор маршрута по таблице | по выбору |
| `03_dns` | запрос к серверу доменных имён и разбор ответа | да |
| `04_http` | разбор сообщения HTTP/1.1 | по выбору |
| `05_retry` | повторная отправка запроса с возрастающим интервалом | да |

Обязательны три задания: `01_packet`, `03_dns`, `05_retry`. Из оставшихся двух выполняется
одно на выбор. Выполнение всех пяти допускается.

## Запуск тестов

Тесты написаны на Python 3 и используют только стандартную библиотеку.

```
make test          все задания
make 01            только 01_packet
make 03            только 03_dns
```

Либо напрямую:

```
cd 01_packet/tests && python3 -m unittest discover -s . -v
```

Тест сообщает, какая строка вывода ожидалась и какая получена. Тесты не читают ваш
исходный код и не накладывают ограничений на его структуру.

## Что сдавать

Каталог задания с исходным кодом, файлом `run.sh` и, если нужно, `build.sh`.
Каталог `tests` изменять не следует: проверка выполняется теми же тестами.
